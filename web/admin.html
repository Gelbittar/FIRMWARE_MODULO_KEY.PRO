PINs de Roles

Jerarquía: master > installer > admin. Fábrica: admin 123456, installer 654321.

Anti-clon de Llaves

Al activar, el módulo escribe 0000 en la ROM de cada llave presentada: si es reescribible (clon RW1990) queda neutralizada y su slot se bloquea (reescribible). Las SÓVICA originales no se alteran. ¡CUIDADO! Si una llave legítima fuera reescribible, también quedaría neutralizada.

Filtro de Familia (1-Wire)

0 = todas las familias. SÓVICA usa familia 0x81.

Sensor de Puerta + Buzzer

GPIO 32 (puerta) y GPIO 33 (buzzer). Si la puerta queda abierta más del tiempo configurado, el slot se bloquea (puerta_abierta) y se notifica.

Notificaciones Push (ntfy.sh)

POST a https://ntfy.sh/ al bloquear slot. Requiere plugin nativo en APK.
