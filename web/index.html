Claves de roles

Cada rol usa una clave distinta como secreto HMAC para identificarse ante el módulo. Con esta pantalla se agrega un administrador y se modifica la clave del instalador. La clave del maestro solo se cambia desde la app GEYLCA Master.

Administrador

Cambiar o resetear el PIN del rol admin (6 dígitos, fábrica 123456). Solo el instalador o el maestro puede modificarlo.

Instalador

Modificar el PIN del rol instalador (6 dígitos). El instalador o el maestro pueden cambiarlo.
